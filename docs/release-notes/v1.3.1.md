# AIDebug v1.3.1 Release Notes

Release date: 2026-08-08

## Live Learning Mode

AIDebug v1.3.1 replaces the static instructional snippets introduced in v1.3.0
with a real compilation and reverse-engineering workflow. The bundled corpus
contains 44 safe C functions covering data movement, arithmetic, comparisons,
bit operations, shifts, calls, loops, buffers, structures, switch dispatch,
and common reverse-engineering patterns.

Opening an exact lesson now:

1. compiles the trusted corpus into a temporary ELF shared object;
2. never loads or executes that artifact;
3. resolves the selected function's real ELF symbol and size;
4. decodes its complete compiler-generated instructions and bytes with
   AIDebug's Capstone pipeline; and
5. reconstructs pseudo-code from that machine code with Ghidra.

The result includes the actual C function used for compilation, compiler
identity, artifact SHA-256, symbol address, assembly bytes, Ghidra output, and
an explicit warning that reconstructed pseudo-code is not original source.
AIDebug does not fall back to handwritten or heuristic pseudo-code when the
compiler or Ghidra is unavailable.

```bash
aidebug --learn
aidebug --learn subtract
aidebug --learn switch-dispatch
```

Exact lesson analysis requires an ELF-capable compiler and Ghidra headless.
