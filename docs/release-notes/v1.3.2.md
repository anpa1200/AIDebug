# AIDebug v1.3.2 Release Notes

Release date: 2026-08-08

## One Real Source File Per Lesson

AIDebug v1.3.2 replaces the shared Learning Mode translation unit with 47
independent source files under `learning/cases/`. Selecting a lesson compiles
only its corresponding file into a temporary x86-64 ELF shared object. The
artifact is analyzed and deleted without being loaded or executed.

The output presents one evidence chain:

1. exact source-file path and source code;
2. compiler identity and artifact SHA-256;
3. resolved function symbol and complete machine-code bytes;
4. Capstone disassembly; and
5. Ghidra pseudo-code reconstructed from that artifact.

Dedicated data-movement cases now include:

```bash
aidebug --learn mov-load
aidebug --learn mov-store
aidebug --learn lea-address
aidebug --learn lea-arithmetic
aidebug --learn movzx
aidebug --learn movsx
aidebug --learn movsxd
aidebug --learn xchg
```

The XCHG source uses explicit inline assembly so the case reliably contains a
real XCHG instruction. The other cases remain simple C and intentionally show
what the selected compiler actually emits. Register names follow the generated
x86-64 System V ABI artifact; for example, the first pointer argument normally
uses RDI rather than Windows x64 RCX.
