# AIDebug v1.3.3 Release Notes

Release date: 2026-08-08

## Real Learning Cases in the Main GUI

AIDebug v1.3.3 integrates the 47 independently compiled learning cases into
the original full-screen Textual interface. `aidebug --learn` opens a catalog
in the left pane. Selecting a case compiles only its standalone C file and
updates the workspace with:

1. the real compiler-generated assembly and instruction bytes;
2. the exact original C source file;
3. Ghidra pseudo-code reconstructed from the temporary ELF;
4. the lesson explanation, register effects, analyst clue, and pitfall; and
5. compiler, function address, source path, and artifact SHA-256 evidence.

The temporary ELF is analyzed and never executed. Results are cached only for
the current GUI session, and pressing `R` recompiles the selected case.

```bash
aidebug --learn
aidebug --learn mov-load
aidebug --learn "data movement"
```

The previous text presentation remains available for automation:

```bash
aidebug --learn --no-tui
aidebug --learn movsxd --no-tui
```
